Interactive site scaffold for the Interactive Developer Universe

Deploy the contents of the /site folder to GitHub Pages, Vercel, or Netlify.

GitHub Pages (recommended quick deploy):
1. Push branch main to GitHub.
2. In repository settings -> Pages -> Source select "main" branch and "/ (root)" or "/site" folder depending on your choice.

Vercel/Netlify:
- Connect the repository and set the build output folder to /site or supply your framework build command.
